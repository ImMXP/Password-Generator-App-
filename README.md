## 🇬🇧 English Description
A simple and efficient Java-based Command Line Interface (CLI) application that generates random passwords with various complexity levels. This tool allows users to specify the desired password length and generates Lowercase, Uppercase, and Mixed-case passwords simultaneously.

### 🚀 Features
- **Customizable Length:** Users can choose a password length between 6 and 18 characters.
- **Input Validation:** Robust error handling for invalid inputs (non-integers) or out-of-range lengths.
- **Multiple Output Formats:** Generates three types of passwords in one go:
  - Lowercase only
  - Uppercase only
  - Mixed (Lowercase & Uppercase)
- **Randomization:** Uses `java.util.Random` to ensure unpredictable character sequences.
